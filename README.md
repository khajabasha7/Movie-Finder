<h1>🎬 Movie App</h1>

<p>
A modern and responsive Movie App built using React that allows users to browse popular movies, search for titles, view detailed information, watch trailers, and manage a favorites list.
</p>

<h2>🚀 Features</h2>
<ul>
  <li>🔍 Search movies by name</li>
  <li>🎬 Browse popular movies</li>
  <li>📄 View movie details (title, rating, release date, overview)</li>
  <li>▶️ Watch trailers (YouTube integration)</li>
  <li>❤️ Add/remove favorites</li>
  <li>💾 Favorites saved using localStorage</li>
  <li>⚡ Fast and optimized with Vite</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li>React (Hooks)</li>
  <li>Vite</li>
  <li>React Router</li>
  <li>Context API</li>
  <li>TMDB API</li>
  <li>CSS</li>
</ul>

<h2>📂 Pages</h2>
<ul>
  <li>🏠 Home Page</li>
  <li>🎥 Movie Details Page</li>
  <li>❤️ Favorites Page</li>
</ul>

<h2>🌐 API</h2>

<pre>
git clone &lt;your-repo-link&gt;

</pre>
